영어 문장 학습

한국어 문장을 적고 영어로 번역해 보세요. 정답은 바로 알려드리지 않고, 스스로 찾도록 안내해 드릴게요.

🔑 AI 연결 (Groq · 제미나이)
  1. Groq Console에 구글 계정 등으로 로그인해요.
  2. “Create API Key” 버튼을 눌러요.
  3. 만들어진 키(gsk_로 시작하는 글자 묶음)를 복사해요.
  4. 아래 칸에 붙여넣고 “저장”을 눌러요.
✨ 제미나이(Gemini) 키
  1. Google AI Studio에 구글 계정으로 로그인해요.
  2. “Create API key”를 눌러 키를 만들고 복사해요.
  3. 아래 칸에 붙여넣고 “저장”을 눌러요.
먼저 쓸 AI
두 키를 모두 넣으면, 먼저 쓸 AI가 한도 초과나 오류로 막혔을 때 다른 AI로 자동으로 넘어가요.
키는 이 기기의 브라우저에만 저장돼요. 다른 사람에게 알려 주지 마세요.
